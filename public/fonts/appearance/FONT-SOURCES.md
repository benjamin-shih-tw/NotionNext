# Optional reader fonts

These fonts are loaded only when a visitor selects them in Appearance Settings.
The bundled WOFF2 files are format conversions of the upstream font files;
the accompanying license texts are included in this directory.

- GenSeki Gothic TW Regular: https://github.com/ButTaiwan/genseki-font (SIL OFL 1.1)
- GenSen Rounded TW Regular: https://github.com/ButTaiwan/gensen-font (SIL OFL 1.1)
- ChenYu LuoYan Thin: https://github.com/Chenyu-otf/chenyuluoyan_thin (SIL OFL 1.1). The web conversion has the internal name Reader LuoYan Web to respect the upstream Reserved Font Name.

Noto Sans TC, Noto Serif TC, and jf open 粉圓 (Huninn) are requested from
Google Fonts when selected; no copies of those fonts are bundled here.
